# 06: Understand Python projects

**What to build:** Make a Python repository's entry points and dependencies visible in the preflight briefing and graph.

**Blocked by:** 05: Graph structure and dependencies.

**Status:** ready-for-agent

- [ ] Common Python project manifests, scripts, packages, and likely entry points are recognized with source evidence.
- [ ] Declared dependencies are distinguished from imports inferred from source code.
- [ ] Internal imports resolve to repository nodes where possible; unresolved or external imports are labeled.
- [ ] CLI-level integration tests use a small Python project and verify both briefing findings and graph edges.
